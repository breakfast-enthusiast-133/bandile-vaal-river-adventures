# Nano Banana image prompts

Paste each prompt into Nano Banana. Save each result as a **.jpg** with the exact file name shown and put it in the folder shown. The pages will pick it up straight away.

To keep the photos looking like one set, end every prompt with the style line below. It is already added to each prompt.

> Style: realistic travel photography, natural light, rich but not oversaturated colours, shot on a full-frame camera, sharp focus, no text, no watermark, no logos.

Aim for about 1600px on the long side. If a picture is bigger than 500 KB, shrink it with squoosh.app so the pages load fast.

## Tips
- Nano Banana sometimes adds text or signs. If it does, ask it to "remove all text and signs" in a follow-up message.
- To make two pictures feel like one set, upload a picture you already like and say "same lighting and colour style as this image".
- Real photos you take at the Vaal yourselves are even better for marks, because the rubric rewards content related to the subject.
